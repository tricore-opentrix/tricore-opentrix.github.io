Roadmap theo bằng chứng

Các bước phát triển theo README và checklist nghiệm thu; chưa cam kết ngày phát hành.

  1. MOCK Portal

    Available

    Source và hướng dẫn demo in-memory; không chứng minh backend hoặc SSO.

    Nguồn M27: README

  2. Stack integration-local

    Self-configured

    Tự cấp Keycloak, PostgreSQL 17, Backend, BFF và HTTPS. Build chưa chứng minh tích hợp chạy.

    Nguồn M28: README

  3. Browser E2E và tái sử dụng Facility

    Not yet

    Checklist yêu cầu identity, quyền, workflow, dữ liệu và hai ứng dụng; chưa có nghiệm thu đầy đủ ở nguồn đối chiếu.

    Nguồn M29: README

  4. APISIX, object storage và production

    Not yet

    README chọn APISIX và MinIO, chưa nhận là năng lực hoàn thành. Không ấn định lịch phát hành.

    Nguồn M30: README

Bốn chip dùng chung: Available; Optional — off by default; Self-configured; Not yet. Chưa gán Optional cho một chức năng khi thiếu bằng chứng mặc định tắt.
