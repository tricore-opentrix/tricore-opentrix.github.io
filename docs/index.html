Tài liệu API đang chờ nguồn OpenAPI chính thức đã đối chiếu runtime.

BLOCKED — thiếu export OpenAPI được duyệt

Chưa có api-docs.json hợp lệ của core-service và helpdesk-service. Không có endpoint hoặc schema thử nghiệm nào được công bố như API sản phẩm.

Yến/Bảo cần cung cấp export, SHA sản phẩm, SHA-256, bằng chứng so runtime và xác nhận quyền phân phối. Playground và tải JSON chính thức sẽ có sau khi nguồn được duyệt.

Playground luôn dùng MOCK; không gửi yêu cầu đến backend.
