01 / SYSTEM MAP

Tổng quan kiến trúc

Backend DX-OS sử dụng Java 21, Spring Boot 3.5.16, modular monolith. Các khối thể hiện ranh giới logic, không có nghĩa là microservice triển khai độc lập.

03 / STACK

Nền tảng công nghệ

BackendJava 21 / Spring Boot 3.5.16
FrontendReact 19 / TypeScript / Vite
DatabasePostgreSQL 17
IdentityOIDC / Keycloak (provider mục tiêu)
QualityGradle, JUnit, Spring Boot Test
Later roadmapAPISIX, MinIO, Node-RED — chưa coi là v0.1.0 hoàn tất
Không nhầm modular monolith với microservices

DX-OS mô tả các module/contract và adapter dùng chung. Việc đặt tên các Core không hàm ý chúng đang chạy thành những dịch vụ độc lập.
