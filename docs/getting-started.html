02 / OPTION A

Chạy MOCK Portal

Đường chạy này được mô tả trong README hiện tại của DX-OS. Yêu cầu Node.js 22.12.0+, npm và trình duyệt.

PowerShell
git clone https://github.com/lexuanbao258-collab/dxos-open-core.git
Set-Location dxos-open-core\frontend
npm.cmd ci
npm.cmd run dev

Truy cập http://127.0.0.1:5173 trên máy phát triển. Dữ liệu hiển thị là synthetic / in-memory MOCK, không phải xác thực hay API thực.

Không dùng làm bằng chứng LIVE

MOCK UI có thể cho phép thao tác đầy đủ trên giao diện nhưng không chứng minh OIDC, quyền tenant/resource hoặc ghi dữ liệu PostgreSQL.

03 / OPTION B

Local Helpdesk + PostgreSQL

Trên Windows, cần PowerShell, Docker Desktop Linux Engine, JDK 21 và port demo trống. Đọc runbook và chạy bước read-only preflight trước khi cho phép tạo CSDL cô lập.

Runbook Helpdesk local ↗Setup script / tùy chọn thực thi ↗
Cảnh báo dữ liệu

Không tự chạy bước -Execute trên tài nguyên dùng chung; không tự tạo/xóa database khi chưa kiểm tra điều kiện của script.

04 / OPTION C

Build integration-local

Khác với MOCK, tùy chọn này cần Keycloak OIDC thật, Portal BFF, Backend, PostgreSQL 17 và Caddy HTTPS ingress với certificate được trình duyệt tin cậy.

PowerShell
Set-Location frontend
npm.cmd ci
npm.cmd run build:integration-local
Set-Location ..

Sau khi cấu hình và khởi chạy đúng toàn bộ dịch vụ, địa chỉ dự kiến của Portal là https://localhost:8443/mvp/helpdesk. Chỉ build không khởi động backend hoặc xác nhận SSO.
