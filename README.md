# TRAKZOR — website giới thiệu DX-OS Open-Core

Repository chứa website tĩnh TRAKZOR và blog của nhóm TriCore.

**Tình trạng:** repository đã được khởi tạo. Nội dung website cần được đẩy lên trước khi bật GitHub Pages. Không coi URL GitHub Pages là đã được xuất bản cho đến khi có deploy thành công.

Nguồn nội dung: bản `TRAKZOR_DEPLOY_READY_20261031.zip` đã rà soát, loại bỏ số liệu khảo sát chưa xác minh.

Để xuất bản: đưa toàn bộ file website vào thư mục gốc nhánh `main`, sau đó vào **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
