Vấn đề

Mỗi ứng dụng xây lại đăng nhập, cơ chế trạng thái và lưu trữ làm tăng chi phí bảo trì. Gộp mọi quy tắc vào nền tảng chung lại khiến Core phụ thuộc một sản phẩm cụ thể. Cần một ranh giới tái sử dụng có thể kiểm tra.

Cách tiếp cận

Bốn năng lực Identity, Workflow, Data Management và API Gateway được tổ chức trong Backend modular monolith. Application định nghĩa use case và quy tắc; adapter kết nối công nghệ cụ thể. DX-OS không phải hệ điều hành máy tính hay mô hình bốn microservice.

Chức năng

Identity có hợp đồng danh tính và quyền; OIDC runtime ở adapter. Workflow có definition, instance, transition, version và history. Data có ObjectStoragePort độc lập provider. Gateway giữ ranh giới HTTP, chuyển tới use case kiểm tra quyền.

Công nghệ

Java 21, Spring Boot, Gradle; PostgreSQL và JDBC/Flyway cho persistence. Keycloak là lựa chọn IdP hiện tại. MinIO là đích object storage, adapter vẫn chờ kiểm chứng. React/TypeScript/Vite thuộc Portal candidate.

Minh chứng

Workflow runtime PR #21, PostgreSQL adapter PR #31, Identity OIDC PR #33 và Gateway handoff PR #46 đã merge. Mỗi nguồn có phạm vi riêng; không gộp các kết quả thành kết luận toàn hệ thống.
